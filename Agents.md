# [Nombre del proyecto] 
ESIBuy: Se desea crear un sistema web de comercio electrónico que permita a los usuarios registrados 
buscar, consultar, comprar y valorar productos en un entorno seguro, escalable y accesible 
desde cualquier navegador web. El sistema debe permitir las opciones básicas de una plataforma 
de este tipo: administración de productos, gestión de pedidos, gestión del carrito de compra, 
configuración de productos favoritos, valoraciones de productos y seguimiento de envíos.
